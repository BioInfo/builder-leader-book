# Field Guide

Companion exercises to *Builder-Leader: The AI Exoskeleton That Crosses the Gap.*

Each entry is short, concrete, and done in your own terminal on your own files. No simulator, no sandbox, no enrollment, no progress tracking. The book tells you what to do; the field guide tells you how.

There's also a standalone, interactive version of this same nine-part guide on AIXplore: each entry is its own post with the exercise running as a live widget in the browser (a scorecard, a calculator, a tracker) instead of on paper. Read either version first; they're independent write-ups of the same nine exercises, not duplicates of each other. Start at [ai.rundatarun.io/series/builder-leader-field-guide](https://ai.rundatarun.io/series/builder-leader-field-guide), or jump straight to the bundled [Field Guide Toolkit](https://ai.rundatarun.io/series/builder-leader-field-guide/toolkit) to run all nine in one sitting.
